제출물 확정 전에만. 확정 후에는 이 스킬을 포함해 아무것도 하지 않는다.

1. DECISIONS.md·VERIFY.md를 읽고 질문을 **한 번에 하나** 낸다. 유형: 왜 이 구조 / 제외 기준과 전후 차이 / AI에 맡긴 것과 직접 확인한 것 / 틀린 답을 내는 입력 / 가장 약한 곳.
2. 응시자가 먼저 답한다. 네가 답하지 않는다.
3. 답에서 실제 코드·VERIFY 기록과 다른 부분만 근거(파일·줄)로 짚는다. 기억 못 하는 숫자는 "VERIFY.md n행을 보라"고만 한다.
4. 5개 질문 후 끝. 모범답안을 만들지 않는다.
