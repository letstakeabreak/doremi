description: 완료 조건을 독립 근거로 검증하고 VERIFY.md에 남긴다. 구현이 "됐다"고 말하기 전에.
---

1. TASK.md의 R마다 V를 정한다. 기대값은 구현에서 베끼지 않는다: README 수치, 실무자 답변, 10~15행 수동 계산, stdlib 독립 재계산 중 하나.
2. 케이스: 정상 1, 경계 2(`>=`와 `>` 양쪽), 빈 입력, 전부 결측, 중복 ID.
3. 같은 명령을 두 번 실행해 출력이 같은지 본다.
4. 단계별 건수 표를 채운다. 제외 사유를 적는다.
5. FAIL이면 재현 → 원인 한 줄 → 최소 수정 → **같은 명령** 재실행. 3번 같은 실패면 멈추고 보고.
   - 새 테스트는 먼저 FAIL을 보고 나서 PASS로 만든다. 처음부터 PASS인 테스트는 의심한다.
   - 테스트를 고쳐서 통과시키지 않는다. 기대값이 틀렸으면 DECISIONS에 적고 응시자 확인.
   - 테스트 0개 실행(`Ran 0`)은 PASS가 아니다.
6. 보고 3줄: 통과 V / 실패·미실행 V / 남은 위험.
